# ЗВЕЗДА СТРОИТЕЛЕЙ · стиль ПОЛИГРАЙ

**ПОЛИГРАЙ** — стиль настольных игр «два в одном»:

- **Офлайн-игра** — один HTML-файл, работает без интернета, позже легко упаковать в APK (WebView).
- **Печать на резку** — поле целиком на A2 (полиарт) + карточки/кубики/фишки/правила на A4.

Играть можно просто в браузере (1 человек + 3 компьютера, или 2–4 человека
за одним экраном), а можно распечатать и играть «на бумаге».

---

## Как играть офлайн

Открой `index.html` в любом браузере — всё работает локально, без интернета.
Фишки-стройтехника выбираются в начале (кран, экскаватор, бульдозер, самосвал…).

Правила: `rules.md`.

---

## Как напечатать и вырезать

```bash
python generate_print.py
```

Результат в папке `print/`:

| Файл | Что это | Формат |
|---|---|---|
| `board_a2.pdf` | поле-звезда с дорожкой из 32 клеток | A2 (420×594 мм) |
| `cards_materials.pdf` | карты стройматериалов (Кирпич/Дерево/Сталь/Стекло, 40 шт) | A4, 9 на лист |
| `cards_events_0/1.pdf` | карты Событий (16 шт) | A4, 9 на лист |
| `pawns.pdf` | 8 жетонов-фишек + подставки | A4 |
| `dice.pdf` | развёртки двух кубиков d6 | A4 |
| `rules.pdf` | краткие правила | A4 |

Порядок печати:
1. Поле печатается на **A2** (полиарт 420×594) — плакатный лист.
2. Карты/кубики/фишки печатаются на **A4** (плотная бумага 200–250 г/м² или полиарт).
3. Всё вырезается по контурам. Карточки — по сплошной линии (лицевая и рубашка
   печатаются с двух сторон одного листа или склеиваются).

Подсказка по ЧПУ-фрезеровке карт из пластика есть в `cnc_cards.py` (репозиторий).

## Как сделать новую игру в этом стиле

Шаблон повторяется в 3 файлах:

1. **`rules.md`** — простые правила: цель, подготовка, ход по шагам, клетки, победа.
2. **`generate_print.py`** — PIL-рисование поля и карточек → PDF.
   Всё считается в миллиметрах (`MM = 300/25.4`), подставляются свои формы,
   цвета и иконки.
3. **`index.html`** — самоиграющаяся версия. Держим состояние машиной
   `phase: roll → moving → build → next`, ИИ — та же машина с задержкой.

Советы для фееричности: мерцающие звёзды, летающие искры, вспышки при броске
кубиков и постройке, пульс активного игрока, конфетти при победе.

## Идея: лог бонусов — это и есть игра

Главная смысловая нагрузка «Звезды Строителей» — не «дойти и построить»,
а **поток бонусов**, который каждый шаг приносит в лог:

- каждый элемент лога — это **получение бонуса** (материал, событие, разгон, этаж);
- бонусы **аддитивные**: кубики дают движение → поле даёт клетку → фишка
  приносит материал → карточка (событие) добавляет эффект — всё складывается;
- один шаг игры = **плюс в лог бонусов**; лог ведётся как поток (stream)
  и как череда событий (event log);
- такой же смысл заложен в печатную версию: клетка на бумаге — та же карточка,
  та же строка в логе.

То есть игра строится не на одной цели, а на **приятном потоке маленьких
бонусов** — и победа лишь собирает этот поток в результат.

## Онлайн?

Пока — полностью офлайн (можно открыть с диска/флешки/телефона).
Онлайн-комнаты добавляются позже поверх этого же файла: состояние игры
отправляется на сервер, клиенты опрашивают его по HTTP.
